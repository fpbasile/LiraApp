Lira · Motion notes

Motion only where it carries meaning.

Every animation either shows where money went (the save), what changed (counts, rings) or where you are (sheets). Feedback lasts under a second and never needs dismissing. All specs are Compose-native: tween, spring, AnimatedContent, SharedTransitionLayout.

Haptics
One CONFIRM tick per save — the only haptic Lira adds on its own. Digits use KEYBOARD_TAP only if the system keyboard vibrates. Never on errors or over-limit.
Easing tokens
standard = FastOutSlowInEasing
emphasized = CubicBezierEasing(0.65f, 0f, 0.35f, 1f)
settle = EaseOutCubic
press = spring(stiffness = 1500f)
Durations
micro 80–160 ms · standard 200–280 ms · save sequence ≤ 920 ms · undo window 4 s. Nothing blocks input at any point.
